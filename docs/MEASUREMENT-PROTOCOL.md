# Протокол вимірювань на реальних пристроях (pre autora)

Тут лише інструкція й порожні таблиці. Нічого з цього ще не виміряно: клітинки заповнює автор під час вимірювання. Якщо щось не вдалося виміряти, напиши в клітинці «не виміряно» і чому. Не вписуй оцінок.

## 0. Перед кожною серією

1. Запиши **версію застосунку**: короткий хеш коміту внизу сторінки (футер «Sonora v0.1 · xxxxxxx») або в консолі браузера (рядок `Sonora build xxxxxxx`). Без хешу результат не можна прив'язати до коду.
2. Запиши **пристрій** (модель, ОС і її версію), **браузер** (назва й версія) та **джерело звуку** (вбудований мікрофон, гарнітура, генератор Sonora).
3. **Частота дискретизації** (vzorkovacia frekvencia): у Chrome і Firefox відкрий консоль (на iPhone через Safari → Develop на Mac) і введи:
   ```js
   new AudioContext().sampleRate
   ```
4. Телефон заряджений або на зарядці, режим економії енергії вимкнений, інші вкладки закриті.
5. Кожен вимір роби **5 разів** (5 opakovaní) і записуй усі 5 значень, а не тільки середнє.

Пристрої з плану: **Chrome і Firefox на ПК, Safari на iPhone 12**. Якщо будуть інші пристрої, додай для них рядки.

## 1. Латентність ладички: AnalyserNode проти AudioWorklet

**Що міряємо:** час від моменту, коли кадр звуку готовий, до моменту, коли результат з'явився на екрані (latencia rámec → obrazovka). Сюди не входить затримка самого мікрофона: вона однакова для обох шляхів.

**Параметри (з коду, перевір лише частоту дискретизації):**
- вікно: `tunerFrameSize`, тобто 2048 відліків при 44,1 і 48 kHz;
- номінальний крок: 75 мс;
- детектор: YIN, той самий на обох шляхах.

**Кроки:**
1. Відкрий сторінку **Tuner** і натисни мікрофон або генератор (Silent sine wave, 110 Hz). Генератор дає однаковий вхід на всіх пристроях, тож для порівняння шляхів він кращий.
2. Перемикачем вибери **AnalyserNode**. Почекай **20 с**.
3. Перепиши рядок під перемикачем: «Frame → screen: median … ms, p95 … ms · YIN … ms · every … ms (n = …)». Або введи в консолі:
   ```js
   __sonoraLatency.analyser.summary()
   ```
   Звідти візьми `total.median`, `total.p95`, `interval.median` і `count`.
4. Скинь статистику: `__sonoraLatency.analyser.reset()`. Якщо консолі нема, як на iPhone без Mac, перезавантаж сторінку.
5. Перемкни на **AudioWorklet** і повтори кроки 2–4 (`__sonoraLatency.worklet…`).
6. Чергуй шляхи, щоб вийшло по **5 повторів** на кожен.

## 2. Розпізнавання акордів: швидкість

У застосунку для цих чисел ще нема автоматичних лічильників, тому міряємо **відеозаписом екрана зі звуком** (záznam obrazovky so zvukom, 60 кадр/с, якщо можна). Потім у відео рахуєш кадри між двома подіями: 1 кадр = 16,7 мс при 60 кадр/с. Точність такого методу приблизно ±1 кадр.

| Що | Початок (подія у відео) | Кінець (подія у відео) |
|---|---|---|
| **Завантаження моделі ШІ** (načítanie modelu) | натискання кнопки «AI» | текст «AI is loading and warming up…» під кнопками змінився на «AI (Basic Pitch neural network): listens…» |
| **Перший результат** (prvý výsledok) | перший удар по струнах після ввімкнення мікрофона | на екрані з'явився перший акорд |
| **Реакція на зміну акорду** (reakcia na zmenu) | удар нового акорду (видно й чути у відео) | на екрані з'явилась назва нового акорду |
| **Стабілізація** (ustálenie) | новий акорд з'явився вперше | назва перестала змінюватися хоча б на 1 с |

Для швидкостей роби кожну подію **5 разів** на кожному рушії: Algorithm (DSP) і AI. Завантаження моделі міряй **двічі**: першого разу з порожнім кешем (приватне вікно), другого разу після перезавантаження сторінки.

| Пристрій | Браузер | Рушій | Що | Повтор | Час [ms] | Примітка (напр. кеш порожній) | Хеш |

| ПК | Chrome | DSP | перший результат | 1 | | | |

## 3. Точність ладички через мікрофон

**Ідея:** генератор тонів на телефоні грає точно відому частоту в динамік, а Sonora на іншому пристрої слухає її мікрофоном. Так перевіряється весь ланцюг: динамік → повітря → мікрофон → YIN.

**Частоти:**
- 110,00 Hz (A2 точно);
- 83,37 Hz (E2 на +20 центів вище);
- 194,87 Hz (G3 на −10 центів нижче);
- E2–E4 стандартного строю: 82,41 / 110,00 / 146,83 / 196,00 / 246,94 / 329,63 Hz.

**Кроки:**
1. На телефоні відкрий генератор тонів (запиши назву застосунку й версію). Вибери синусоїду, середню гучність, телефон на відстані приблизно 30 см від мікрофона.
2. Sonora: сторінка **Tuner**, режим Chromatic, A4 = 440 Hz.
3. Для кожної частоти: увімкни тон, почекай **3 с**, перепиши «… Hz · measured». Повтори **5 разів**: вимкни, увімкни, знову почекай 3 с.
4. Якщо Sonora нічого не показує («—») довше 3 с, це **нерозпізнаний** вимір (nerozpoznané).

**Як рахувати** (для кожного виміру):
- похибка в центах (chyba v centoch) = `1200 · log2(f_odhad / f_skutočná)`;
- **октавна помилка** (oktávová chyba): похибка ближча до ±1200 c, ніж до 0. Таку не включай у середнє, рахуй окремо.

Підсумок для кожної частоти: **середня абсолютна похибка** (priemerná absolútna chyba), **максимум** |похибки|, **частка вимірів у ±5 c**, кількість **нерозпізнаних** і **октавних** помилок.

Обмеження: Sonora показує частоту з точністю до 0,1 Hz. Це до ±0,8 c при 110 Hz і до ±1 c при 83 Hz, тож різниці менші за 1 c цим методом не видно.

## 4. Додаткові перевірки на реальному звуку

### 4a. Тихий довгий тон у реальній кімнаті (brána úrovne)
1. Сторінка **Chords**, мікрофон. 10 с не грай нічого: брама вивчає кімнату.
2. Тихо вдар один акорд і дай йому звучати, доки не затихне (30 с і довше).
3. Запиши, через скільки секунд акорд зник з екрана і чи він зник раніше, ніж перестав бути чутним.
4. Те саме з увімкненим вентилятором або іншим рівним шумом. Запиши, чи брама не застрягла відкритою (акорди «з шуму») довше ніж на 30 с.

| Пристрій | Кімната / шум | Акорд | Звучав [s] | Видно на екрані [s] | Хибні акорди з шуму? | Хеш |
|---|---|---|---|---|---|---|

### 4b. Окремі струни: «одна нота, а не акорд»
1. Сторінка **Chords**, Algorithm, усі акорди.
2. Зіграй кожну відкриту струну окремо (E2, A2, D3, G3, B3, E4), кожну **3 рази**.
3. Запиши, що показала Sonora: «One note (…)», акорд чи нічого.
4. Додатково запиши 5–10 дублів на сторінці **Record** з міткою «one string» (`none-string`): у тестовому наборі таких записів досі нема.
