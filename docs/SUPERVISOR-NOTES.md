## Що ще можна зробити (за бажанням)

- Тихий довгий тон у реальній кімнаті та запис на телефоні (протокол, 4a і 4c).
- Точність ладички через мікрофон із записаними числами: зараз записано лише, що частоти збіглися.
- Друга порція записів однієї струни, якщо правило «одна нота» колись покращуватимуть: на ній треба буде чесно перевірити зміну.

## Обмеження

- На тестових гравцях точність нижча, ніж на dev. Наприклад, ШІ на 24 акордах: 77,5 % на dev проти 64,0 % на test. Цифри на test — це незалежна оцінка; старі цифри на всьому GuitarSet такою не були.
- Поріг DSP для септакордів (extendedMargin = 1) означає, що алгоритм майже не називає 7, maj7, m7 тощо: він показує простіший акорд. Так вийшло менше хибних акордів (на dev 6,8 % вікон проти 11,7 %). Для септакордів є ШІ.
- Вимірювання на пристроях — один прогін на кожну комбінацію, тож p95 спирається на 13–20 змін акорду.
