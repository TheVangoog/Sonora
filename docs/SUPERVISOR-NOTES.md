## Що може зробити тільки автор

1. Заповнити таблиці з `docs/MEASUREMENT-PROTOCOL.md` на ПК (Chrome, Firefox) і iPhone 12. Пункти:
   - затримка ладички (обидва шляхи);
   - швидкість акордів;
   - точність ладички за генератором тонів;
   - брама в кімнаті;
   - окремі струни;
   - Record на телефоні.
2. Записати 5–10 дублів однієї струни (`none-string`) на сторінці Record. Без них правило «одна нота» не перевірене на справжньому звуці.

## Чесні застереження для тексту роботи

- На тестових гравцях точність нижча, ніж на dev. Наприклад, ШІ на 24 акордах: 77,5 % на dev проти 64,0 % на test. Цифри на test — це незалежна оцінка; старі цифри на всьому GuitarSet такою не були.
- Поріг DSP для септакордів (extendedMargin = 1) означає, що алгоритм майже не називає 7, maj7, m7 тощо: він показує простіший акорд. Так вийшло менше хибних акордів (на dev 6,8 % вікон проти 11,7 %). Для септакордів є ШІ.
- Затримки поміряні лише в Chrome на ПК; на телефоні цифри можуть бути інші.
