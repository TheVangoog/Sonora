# Як увімкнути бекенд в інтернеті (Vercel + Turso, безкоштовно)

Бекенд — це Express API в тому самому проєкті Vercel, що й сайт. Він працює як одна функція (`api/index.ts`), тож окремого сервера немає. Дані (акаунти, налаштування, статистика) лежать у базі **Turso**: це SQLite в інтернеті з безкоштовним планом.

Потрібно дві речі: створити базу в Turso і вписати у Vercel дві змінні. Це займе приблизно 10 хвилин.

## 1. Turso: створити базу

1. Зайди на **turso.tech** і зареєструйся (можна через GitHub). Безкоштовного плану вистачить.
2. Створи нову базу (**Create Database**). Назва, наприклад, `sonora`; регіон — найближчий до Vercel (Європа, наприклад Frankfurt).
3. На сторінці бази скопіюй її **URL**. Він виглядає як `libsql://sonora-<твоє-ім'я>.turso.io`.
4. Там же створи **токен** (Create Token / Generate Token) з правом читання й запису і без терміну дії. Скопіюй його: Turso покаже його лише один раз.

Таблиці створювати не треба: API зробить це сам під час першого запиту.

## 2. Vercel: вписати змінні

1. Відкрий проєкт Sonora на **vercel.com** → **Settings** → **Environment Variables**.
2. Додай дві змінні для середовищ **Production** і **Preview**:

   | Name | Value |
   |---|---|
   | `TURSO_DATABASE_URL` | URL з кроку 1.3 (`libsql://…turso.io`) |
   | `TURSO_AUTH_TOKEN` | токен з кроку 1.4 |

3. Збережи. Змінні почнуть діяти після нового деплою: або злий гілку `backend` у `main` і запуш, або у Vercel → **Deployments** → останній деплой → **Redeploy**.

Токен нікуди не вписуй у код і не надсилай у чат: він має бути тільки у Vercel.

## 3. Перевірка

1. Відкрий **https://sonora-one-wheat.vercel.app/api/health**.
   - `{"ok":true}`: усе працює, база підключена.
   - `{"error":"The API is not configured: TURSO_DATABASE_URL is not set…"}`: змінні не вписані або ще не було нового деплою.
   - Інша помилка 500: найчастіше токен або URL неправильний. Подивись у Vercel → Deployments → деплой → **Functions** / **Logs**.
   - 404: функцію не зібрано. Подивись лог збірки (Build Logs) і надішли мені помилку.
2. Відкрий сайт → **Account** → **Create account**. Після реєстрації має з'явитися «Signed in as …».
3. Зміни A4 на сторінці Tuner, потім відкрий сайт в іншому браузері й увійди: має бути те саме A4.
4. Увімкни мікрофон на Tuner щонайменше на 5 с, потім вимкни. На сторінці Account має з'явитися статистика.

## Що не перевірено

Я не міг зібрати проєкт саме на Vercel: для цього потрібен акаунт, а локальний `vercel build` заблокований налаштуваннями. Перевірено:
- функція з `api/index.ts` на локальному http-сервері (з базою і без неї);
- усі тести на файловій базі libSQL;
- вхід, налаштування й статистика в браузері з локальним API.

Якщо під час першого деплою з'явиться помилка збірки функції (наприклад, про імпорти `.ts`), надішли мені текст із Build Logs, і я виправлю.

## Локально (для розробки)

```sh
npm run server   # API на http://localhost:3001, база у файлі server/data/sonora.db
npm run dev      # сайт; /api іде на локальний API
```

Без змінних `TURSO_*` локальний API працює з файлом, тож Turso для розробки не потрібен.
